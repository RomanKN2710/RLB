Einmalig: das Handy einrichten

  1. Auf dem Android-Handy Firefox installieren, darin die Erweiterung «Tampermonkey».
  2. Firefox › Einstellungen › Erweitert › «Links in Apps öffnen» auf «Nie». Sonst springt die kicker-App auf.
  3. In Firefox in der RLB-App anmelden: Admin › Werkzeuge › «kicker-Seiten vom Handy senden» › «Tampermonkey-Skript installieren», bestätigen.
  4. Fertig. iPhone oder kein Handy zur Hand: Quelltext am Computer einfügen, siehe Folie 11.

So sieht der Knopf unter Admin › Werkzeuge aus:

RLB-Admin-Handbuch · 9

Das Skript enthält die Adresse der App und einen Schlüssel; es funktioniert nur, wenn man als Admin angemeldet ist, um es zu installieren. Wird das Skript verbessert, steht die neue Version an derselben Stelle; einfach nochmals installieren.
