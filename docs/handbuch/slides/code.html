Weiterentwicklung

Die App selbst ändern

Wo der Code liegt

GitHub-Repository «romankn2710/rlb». Jede Änderung auf «main» ist nach etwa zwei Minuten live (Vercel).

Wie man ändert

In Claude Code (claude.ai/code) eine Sitzung mit dem Repository starten und auf Deutsch beschreiben, was anders werden soll.

Zugang

Zugriff auf das GitHub-Repository und das Vercel-Projekt. Beides vergibt Roman.

Drei Regeln

Schlüssel nur in Vercel, nie in einen Chat. Datenkorrekturen als einmalige Schritte. Erst testen, dann veröffentlichen.

RLB-Admin-Handbuch · 19

Für den normalen Spielbetrieb braucht niemand Zugriff auf den Code. Wer etwas an der App ändern will, braucht ein GitHub-Konto mit Zugriff auf das Repository. Datenkorrekturen in der Produktion laufen als einmalige Schritte in der Datei src/lib/migrations.js; sie werden beim nächsten Öffnen der Admin-Seite eingespielt und protokolliert. Die Tests laufen mit «npm test» und automatisch bei GitHub.
